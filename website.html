matoga

材质贴图对比工具

专为 Minecraft 材质开发者设计的高效贴图对比工具。支持双文件夹差异比对、 3D PBR 实时预览、HDRI 环境光渲染、批量操作与多语言界面。

立即下载 查看源码

功能特性

为材质开发者打造的全方位工具链

双文件夹对比

同时加载两个材质包文件夹，自动匹配对应贴图，一目了然查看差异与缺失文件。

差异可视化

像素级差异对比、覆盖率统计、一致性评分、漏斗图与热力图，数据驱动决策。

3D PBR 实时预览

基于 Three.js 的实时光栅化渲染，支持金属度、粗糙度、法线、视差遮蔽等完整 PBR 工作流。

HDRI 环境光照

内置 HDRI 预设库与程序化天空盒，支持太阳角度、云层、瑞利散射等参数实时调节。

批量操作

批量复制、替换、删除贴图，一键撤回操作历史，大幅提升材质包整理效率。

多语言 & 导出

中英文双语界面一键切换，对比结果可导出为 HTML 报告，方便分享与存档。

安装指南

macOS .dmg 安装步骤 & Gatekeeper 说明
1

下载 .dmg 文件，双击挂载磁盘镜像

2

将 matoga.app 拖入 Applications 文件夹

3

首次打开时 macOS Gatekeeper 可能拦截，前往 系统设置 → 隐私与安全性，点击"仍要打开"

# 或通过终端移除隔离属性
xattr -cr /Applications/matoga.app
Windows .exe 安装 & 便携版说明
1

下载 .exe 安装程序，双击运行

2

选择安装路径（默认 C:\Program Files\matoga），完成安装

3

从开始菜单或桌面快捷方式启动

便携版 .zip 无需安装，解压后直接运行 matoga.exe，配置文件存储在同目录下

Linux AppImage / deb / rpm 安装

AppImage（推荐）

# 添加执行权限并运行
chmod +x matoga-1.0.AppImage
./matoga-1.0.AppImage

deb (Debian/Ubuntu)

sudo dpkg -i matoga-1.0.deb
sudo apt install -f # 修复依赖

rpm (Fedora/RHEL)

sudo rpm -i matoga-1.0.rpm

校验和验证

下载完成后，建议验证文件完整性以确保安全：

# macOS / Linux
shasum -a 256 matoga-1.0.2-arm64.dmg

# Windows (PowerShell)
Get-FileHash matoga.Setup.1.0.2.exe -Algorithm SHA256

校验值请对照 GitHub Releases 页面公布的 SHA-256 值

快速上手

三步开始你的材质对比工作流

01

选择文件夹

点击左侧"选择"按钮加载基准材质包，右侧加载对比材质包。也支持拖拽文件夹到对应卡片。

02

开始对比

点击"开始对比"按钮，工具将自动匹配两侧贴图并生成差异报告，支持按文件夹分类、递归扫描与哈希校验。

03

预览 & 操作

点击表格中任意材质行，右侧面板展示 2D 贴图预览与 3D PBR 实时渲染。支持替换、删除、批量复制等操作。

键盘快捷键

搜索贴图 ⌘K / Ctrl+K
撤回操作 ⌘Z / Ctrl+Z
表格视图 Ctrl+1
可视化视图 Ctrl+2

API 参考

渲染进程可通过 window.api 访问主进程 IPC 桥

文件夹 / Folder

  • selectFolder(side)
  • readEntries(path, ignore)
  • readRecursive(path, ignore)
  • pickFolder() · createFolder(path)

文件 / File

  • hashFile(path) · copyFile(src, dest)
  • backupFile(path) · deleteFile(path)
  • selectFile() · selectHDRFile()

Shell & 配置

  • openPath(p) · showInFolder(p)
  • getPathForFile(file)
  • getConfig() · setConfig(patch)
  • clearConfig()

HDRI 预设

  • listHdrPresets()
  • hdrThumbInfo(fullPath)
  • saveHdrThumb(fullPath, dataUrl)

配置文件示例

用户配置持久化于 config.json，通过 setConfig 传入 patch 对象局部更新。 

// config.json — 由 getConfig() / setConfig(patch) 读写
{
  "theme": "dark",
  "lang": "zh-CN",
  "ignore": [".DS_Store", "thumbs.db"],
  "m3d": { "roughness": 0.8, "metalness": 0.2 },
  "hdri": "studio_soft.exr"
}
