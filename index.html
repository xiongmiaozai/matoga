常见问题

FAQ

支持 Bedrock 版吗？

目前主要针对 Java 版的 OptiFine / Iris PBR 格式。Bedrock 版 MER 格式支持正在计划中。

导出的材质包直接就能用吗？

是的，导出后按目录结构放好，进游戏加载光影就能看到效果。

需要联网吗？

完全本地运行，不需要联网。你的贴图文件不会上传到任何地方。
