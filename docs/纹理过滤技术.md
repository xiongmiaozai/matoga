## 概述

当纹理被映射到屏幕时，屏幕像素与纹素（texel）之间通常不是一一对应：一个像素可能覆盖多个纹素（缩小，minification），或多个像素共享一个纹素（放大，magnification）。**纹理过滤**就是决定如何从纹理中采样颜色的算法。

- **放大过滤 (magFilter)**：纹理被放大时（像素 > 纹素）
- **缩小过滤 (minFilter)**：纹理被缩小时（像素 < 纹素）

不同的过滤策略在**画质**与**性能**之间做权衡。

---

## 最近邻插值 (Nearest Neighbor)

最简单快速的过滤方式：取距离采样坐标最近的那个纹素的颜色。

```
采样坐标 (u, v) → 取整 → texel[floor(u+0.5), floor(v+0.5)]
```

- **优点**：计算量极小，保留像素硬边，适合像素风/像素艺术纹理
- **缺点**：放大时锯齿（块状）明显，缩小时产生摩尔纹与闪烁
- **Three.js 常量**：`THREE.NearestFilter`

> 在像素贴图、UI 图标、需要保留锐利边缘的法线/查找表纹理中常用此模式。

---

## 双线性插值 (Bilinear)

在采样坐标周围的 **4 个纹素**之间做两次线性插值（先沿 X，再沿 Y），得到平滑过渡的颜色。

```
c0 = texel[x,   y]      c1 = texel[x+1, y]
c2 = texel[x,   y+1]    c3 = texel[x+1, y+1]
top    = lerp(c0, c1, fx)
bottom = lerp(c2, c3, fx)
result = lerp(top, bottom, fy)
```

- **优点**：画面平滑，无明显块状锯齿，性能开销低
- **缺点**：缩小时仍会出现远处摩尔纹与闪烁（未使用 Mipmap 时）；放远处斜视角下细节模糊
- **Three.js 常量**：`THREE.LinearFilter`

> 这是大多数引擎的默认过滤方式。

---

## Mipmap 多级渐远纹理

Mipmap 是一组长宽逐级减半的纹理金字塔（原图、1/2、1/4、… 1×1），由原始纹理自动生成。

```
Level 0: 256×256  (原图)
Level 1: 128×128
Level 2:  64×64
...
Level 8:   1×1
```

- **作用**：远处采样时从合适的小级别取值，避免在一张高分辨率纹理上跨多个纹素采样造成的**摩尔纹、闪烁、锯齿**
- **代价**：额外占用约 1/3 显存（1 + 1/4 + 1/16 + … ≈ 4/3）
- **Three.js**：`texture.generateMipmaps = true`（默认开），且 `minFilter` 必须是 `*Mipmap*` 系列才会生效

> Mipmap 仅作用于**缩小过滤**；放大过滤仍由 magFilter 决定。

---

## 三线性插值 (Trilinear)

在 Mipmap 的**两个相邻级别**上各做一次双线性插值，再按级别权重做一次线性插值——共 8 个纹素参与。

```
c_level_n   = bilinear(level n,   u, v)
c_level_n+1 = bilinear(level n+1, u, v)
result      = lerp(c_level_n, c_level_n+1, level_frac)
```

- **优点**：不同 Mipmap 级别间过渡平滑，消除级别切换处的可见跳变（banding）
- **缺点**：斜视角下远处仍偏模糊（各向同性问题）
- **Three.js 常量**：`THREE.LinearMipmapLinearFilter`（最常用的高质量默认）

---

## 各向异性过滤 (Anisotropic Filtering)

传统过滤（含三线性）在采样时使用**正方形**采样核。当表面与视线成大角度（如地面延伸到远处）时，一个像素在纹理空间投影成**细长椭圆**，正方形核要么欠采样（模糊）要么过采样（浪费）。

各向异性过滤沿纹理拉伸方向取**多个样本**（沿椭圆长轴排布），再平均：

```
各向异性等级 AF = 2 / 4 / 8 / 16
→ 沿长轴最多取 AF 个样本，分别双线性采样后求平均
```

- **优点**：斜视角下远处纹理清晰锐利，地面/道路/远墙效果显著提升
- **代价**：随 AF 等级线性增加采样开销（现代 GPU 上 4×~8× 几乎无感，16× 仍有可观开销）
- **Three.js**：`texture.anisotropy = N`，N 受 `renderer.capabilities.getMaxAnisotropy()` 限制；通常配合 `LinearMipmapLinearFilter` 使用

> AF 等级建议：2× 轻量、4× 平衡、8× 高质量、16× 极致。

---

## 双三次插值 (Bicubic)

在采样坐标周围 **4×4 = 16 个纹素**之间做三次多项式插值（如 Catmull-Rum 核），比双线性更平滑且边缘更锐利。

- **优点**：放大时过渡极平滑，无双线性的"格子感"，适合高倍放大预览
- **缺点**：开销约为双线性的 4 倍以上；WebGL 原生不直接支持，需自定义着色器实现
- **Three.js**：无内置常量，需通过 `onBeforeCompile` 注入自定义采样代码

> 本项目 3D 预览暂不实现双三次，2D 预览的"平滑"档由浏览器 `image-rendering: auto` 提供近似双线性效果。

## 技术对比

| 技术 | 参与纹素 | Mipmap | 斜视角清晰度 | 性能 | 适用场景 |
|------|---------|--------|-------------|------|---------|
| 最近邻 | 1 | 否 | 差 | 极快 | 像素风、查找表、保留硬边 |
| 双线性 | 4 | 否 | 一般 | 快 | 通用默认 |
| 三线性 | 8 | 是 | 较好（远处偏糊） | 中 | 通用高质量 |
| 各向异性 4× | ~8-16 | 是 | 好 | 中 | 地面/远墙等斜视角 |
| 各向异性 16× | ~32-64 | 是 | 极好 | 较慢 | 极致画质 |
| 双三次 | 16 | 否 | 好（仅放大） | 慢 | 高倍放大预览 |

## 在本项目中的应用

本项目（matoga）在 3D 预览面板「高级」标签页提供纹理过滤模式切换，作用于所有材质纹理（主贴图、法线、粗糙度、金属度、自发光、高度图）。

### 模式映射（Three.js）

| UI 模式 | magFilter | minFilter | generateMipmaps | anisotropy |
|---------|-----------|-----------|-----------------|------------|
| 最近邻 | NearestFilter | NearestFilter | false | 1 |
| 双线性 | LinearFilter | LinearFilter | false | 1 |
| 三线性 | LinearFilter | LinearMipmapLinearFilter | true | 1 |
| 各向异性 | LinearFilter | LinearMipmapLinearFilter | true | N（可调） |

### 2D 预览

2D 预览使用浏览器 `<img>` 的 CSS `image-rendering` 属性近似实现：

- **平滑**：`image-rendering: auto`（浏览器双线性/双三次）
- **像素化**：`image-rendering: pixelated`（最近邻，适合像素贴图检查）

> 注：CSS 仅能提供这两档，无法实现 Mipmap/各向异性；完整过滤能力见 3D 预览。

### 相关代码

- `src/material3d.js` — `setTextureFilter()` / `setMipmapsEnabled()` / `setAnisotropyLevel()`
- `src/preview2d.js` — 2D `image-rendering` 切换
- UI 控件：`index.html` 高级标签页 + 2D 工具栏
